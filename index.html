Requête Description
SELECT Pays.Capitale, Clientele.Societe FROM Pays INNER JOIN Cliente ON Pays.NoPays = Clientele.NoPays WHERE Pays.Capitale = "Paris"; On veut vérifier les coordonnées des clients parisiens : liste triée par société.
SELECT Pays.PaysEN, Fournisseur.Societe, Fournisseur.Ville, Produit.NomProd, Produit.CountAchat FROM Pays INNER JOIN ( Fournisseur INNER JOIN Produits ON Fournisseur.NoFour = Produits.NoFour ) ON Pays.NoPays = Fournisseur.NoPays WHERE (Pays.PaysEN = "United States") AND (Produit.CoutAchat < 25); Quels sont les produits de provenance des Etats-Unis avec un cout de moins de 25€ ? On veut les connaître noms et prix, nom du fournisseur et ville.
SELECT Categorie.NomCateg, Produit.CoutAchat, Fournisseur.Societe, Pays.PaysFR FROM ( Pays INNER JOIN ( Fournisseur INNER JOIN Categorie INNER JOIN Produit ON Categorie.CodeCateg = Produit.CodeCateg ) ON Fournisseur.NoFour = Produit.NoFour ) ON Pays.NoPays = Fournisseur.NoPays WHERE ( (Categorie.NomCateg = "Viandes") OR (Categorie.NomCateg LIKE "Poissons) ) AND Produit.CoutAchat > 50; Quels sont les produits (avec fournisseur et pays de provenance) de catégorie viandes ou poissons ayant un coût d’achat de plus de 50€ ?
SELECT Fournisseur.Societe, Produit.NomProd, Categorie.NomCateg FROM Fournisseur INNER JOIN ( Categorie INNER JOIN Produit ON Categorie.CodeCateg = Produit.Categ ) ON Fournisseur.NoFour = Produit.NoFour WHERE (Categorie.NomCateg) = "Viandes" OR (Categorie.NomCateg LIKE "Poissons*"); Quels fournisseurs proposent de la viande ou du poisson ?
SELECT Fournisseur.Societe, Produit.NomProd, Categorie.NomCateg FROM Fournisseur INNER JOIN ( Categorie INNER JOIN Produit ON Categorie.CodeCateg = Produit.CodeCateg ) ON Fournisseur.NoFour = Produit.NoFour WHERE (Categorie.NomCateg = "Viande") AND (Categorie.NomCateg LIKE "Poissons*"); Quels fournisseurs proposent de la viande et du poisson ?
SELECT Produit.SteParUnit, Produit.NomProd FROM Produit WHERE (Produit.QteParUnit LIKE "*cartons") OR (Produit.QteParUnit LIKE "*verres"); Quels sont les produits conditionnés dans du carton ou dans du verre ?
SELECT TOP 3 Clientele.Contact, Commande.CodeCli, Commande.DateCde FROM Clientele INNER JOIN Commande ON Clientele.CodeCli = Commande.CodeCli WHERE Clientele.Contact = "Max Deschamps"; Donner les 3 dernières commandes du client Max Deschamps ?
SELECT F.NoFour, F.NomFour FROM ( Fournisseur AS F INNER JOIN Produit AS P ON F.NoFour = P.NoFour ) INNER JOIN Categorie AS C ON P.CodeCat = C.CodeCat GROUP BY F.NoFour, F.NomFour HAVING Sum(IIf(C.NomCat <> "Desserts", 1, 0)) = 0; Quels fournisseurs ne proposent que des desserts ?
SELECT F.NoFour, F.NomFour, F.Pays FROM Fournisseur AS F LEFT JOIN Produit AS P ON F.NoFour = P.NoFour INNER JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf produit] WHERE (F.Pays <> "France") AND P.NoFour Is Null; Quels fournisseurs hors France n’ont pas encore de produits au catalogue de Kdou ?
SELECT C1.NoClient AS Client1, C1.NomClient AS NomClient1, C2.NoClient AS Client2, C2.NomClient AS NomClient2 FROM Client AS C1, Client AS C2 INNER JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf produit] WHERE C1.Ville = "Paris" AND C2.Ville = "Paris" AND C1.NoClient < C2.NoClient; Pour optimiser les livraisons, on veut savoir quels couples de clients sont situés à Paris.
SELECT Sum([Quantité] * [CoutAchat]) AS CATotal FROM ( ( Pays INNER JOIN Fournisseur ON Pays.NoPays = Fournisseur.NoPays ) INNER JOIN Produits ON Fournisseur.NoFour = Produits.NoFour ) INNER JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf produit] WHERE Pays.UE = "Membre"; Dans une réflexion en lien avec l’origine de ses produits : On veut comme indicateur le CA total généré à ce jour avec les fournisseurs de l’UE ? de la requête 2
SELECT Sum( [Quantité] * [CoutAchat] * (1 - [DetailCommande].[Remise (%)]) ) AS CATotal, Commande.DateCde FROM Commande INNER JOIN ( Categorie INNER JOIN( Produit INNER JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf produit] ) ON Categorie.CodeCateg = Produit.CodeCateg ) ON Commande.[N° commande] = DetailCommande.[N° commande] WHERE ( ( (Categorie.NomCateg) = "Desserts" OR (Categorie.NomCateg) = "Boissons" ) ) GROUP BY Commande.DateCde; Dans une réflexion en lien avec la santé : On veut comme indicateur le chiffre d’affaire généré (montant total des ventes) annuel pour les catégories desserts ou boissons.
SELECT Count(Produit.RefProd) AS CompteDeRefProd FROM ( Categorie INNER JOIN Produit ON Categorie.CodeCateg = Produit.CodeCateg ) LEFT JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf produit] WHERE Categorie.NomCateg = "Vivandes" HAVING Count (DetailCommande.[N° commande]) IS NULL; Dans une réflexion en lien avec l’offre commerciale : Calcul de l’indicateur nombre de produits carnés non commandés actuellement ?
SELECT Clientele.CodeCli, Count(Commande.[N° commande]) AS [CompteDeN° commande] FROM Clientele INNER JOIN Commande ON Categorie.CodeCateg = Produit.CodeCateg LEFT JOIN DetailCommande ON Produit.RefProd = DetailCommande.[Réf produit] WHERE Categorie.NomCateg = "Vivandes" HAVING Count (DetailCommande.[N° commande]) IS NULL; Dans une réflexion sur le partenariat client : A-t-on des clients pilotes d’un réseau partenaire ayant autant de commandes que les clients partenaires ?
